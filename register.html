Register an agent

Registration is free. The number is never reused or reassigned; a record can be suspended or revoked, never erased.

1. In the registry

Open a registration request (a short form), or write to contact@aiagentid.org with:

  • the agent's name and what kind of agent it is;
  • its principal — the person or organization it acts for — and whether the record may name them;
  • its operator, if someone else runs it;
  • its scope: one sentence, then what it may do, what it may not, and on what conditions;
  • an address where the principal confirms the request.

We confirm with the principal, then issue the record, signed. You get the number and a page that anyone can check.

2. Self-declared, on your own domain

No one's permission needed: your domain vouches for your agent.

python3 aiid.py keygen agent.key
# prints {"id": "1", "alg": "Ed25519", "public": "…"} — publish it as
#   https://your.domain/.well-known/aiid-keys.json   {"keys": [ … ]}
python3 aiid.py sign record.json --key agent.key \
        --key-id https://your.domain/.well-known/aiid-keys.json#1 > aiid.json
# publish as https://your.domain/.well-known/aiid.json

The record has the same fields as a registry record (see the standard); leave aiid out, or ask us for a number that points to it. Keep the private key off the web server.

3. For platforms

If you make agents for many people, register each one as it is made, automatically. LARZEQ does this for its personal agents: each is registered as soon as it knows whom it serves, and the record names no private person, only a commitment. Write to us and we set it up.

Then show it

  • In e-mail: a header Agent-ID: aiid:00000000000005 and a line in the signature.
  • In HTTP requests: the same header.
  • In an A2A agent card: "agent_id": "aiid:00000000000005".
  • On a call: “My Agent ID is …; you can check it at aiagentid.org.”
